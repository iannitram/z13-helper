# Goal 1 map — Boondock (historical snapshot retired)

This file used to be an implementation plan for removing Docker and VM behavior from Boondock. That plan is no longer a current work brief: the script and profile integration have since gained separate session-only and hardware-only command paths. The underlying cleanup is still listed as pending in the current [roadmap](../ROADMAP.md); this page intentionally does not repeat the old line-numbered analysis or present its steps as approved work.

For current behavior, read [`tooling/boondock`](../../tooling/boondock) and its profile-hook caller in [`src/profiles.py`](../../src/profiles.py). Built-in Boondock profile hooks run `session-on` / `session-off`; standalone `hardware-on` / `hardware-off` commands own the low-power profile and TDP actions. The script still contains the background-service, container and optional VM handling described in its source comments. Any cleanup proposal should start from the current roadmap and code, not the retired checklist that previously lived here.
